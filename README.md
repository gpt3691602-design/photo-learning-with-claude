# צילום עם בינה

אפליקציית ווב בעברית ללימוד יסודות הצילום במצלמת SLR, לכל גיל. האפליקציה היא המורה: היא מלמדת, בודקת כל תשובה, מסבירה טעויות, נותנת שאלה דומה לניסיון נוסף, ומחזירה את התלמיד לנושאים שעוד לא יושבים.

אין שרת, אין הרשמה ואין בינה מלאכותית חיצונית. ההתקדמות נשמרת רק במכשיר של התלמיד.

## מה יש באפליקציה

- **15 שיעורים** עם בוחן לכל שיעור (58 שאלות, ועוד 51 שאלות תאומה).
- **סוגי שאלות:** בחירה, גלגלת ערכים כמו במצלמה, סידור, לחיצה על תמונה, ומשימות במצלמה הווירטואלית.
- **מצלמה וירטואלית** עם 4 סצנות ו-10 אתגרים.
- **15 משימות שטח**, עם שאלת סיכום ותגובה אישית.
- **״כדאי לחזור״** – השאלות שהתלמיד טעה בהן פעמיים, לתרגול חוזר.
- **מבחן מסכם** שנפתח אחרי שכל השיעורים עוברים ב-70%, ותעודה מ-80%.
- **גיבוי** – קוד להעברת ההתקדמות בין מכשירים.

## העלאה ל-GitHub (דרך הדפדפן, בלי טרמינל)

1. פותחים את קובץ ה-ZIP במחשב (לחיצה ימנית ← חילוץ הכל).
2. נכנסים ל-github.com ← למעלה מימין **+** ← **New repository**.
3. ב-Repository name כותבים שם באנגלית בלי רווחים, למשל `photo-learning`. משאירים Public ולוחצים **Create repository**.
4. בעמוד שנפתח לוחצים על הקישור **uploading an existing file**.
5. פותחים את התיקייה שחולצה, מסמנים את **כל מה שבתוכה** (index.html, README.md, התיקיות css ו-js) וגוררים לחלון של GitHub.
   חשוב: גוררים את התוכן של התיקייה, לא את התיקייה עצמה – כך ש-index.html יהיה בשורש המאגר.
6. למטה לוחצים **Commit changes**.

## פרסום ב-Vercel

1. נכנסים ל-vercel.com ומתחברים עם חשבון ה-GitHub.
2. **Add New** ← **Project**.
3. ליד המאגר `photo-learning` לוחצים **Import**. אם הוא לא מופיע – לוחצים **Adjust GitHub App Permissions** ומאשרים גישה למאגר.
4. ב-Framework Preset בוחרים **Other**. לא משנים שום הגדרה אחרת.
5. **Deploy**. אחרי כחצי דקה מתקבל קישור לאתר.

מעכשיו, כל שינוי שתעלו למאגר יתעדכן באתר אוטומטית.

## הרצה מקומית (לא חובה)

```bash
npx serve .
# או
python3 -m http.server 8000
```

פתיחה ישירה של index.html בדפדפן לא תעבוד, כי הקוד משתמש ב-JavaScript modules.

## מבנה הקבצים

```
index.html             מעטפת האפליקציה
css/styles.css         עיצוב (בהיר/כהה, RTL, מותאם לנייד)
js/app.js              מסכים, מנוע הבוחן, חזרה, גיבוי
js/simulator.js        המצלמה הווירטואלית והאתגרים
js/data/lessons.js     טקסט השיעורים
js/data/quizzes.js     השאלות ושאלות התאומה
js/data/extras.js      משימות שטח ומילון מונחים
```

## עריכת תוכן

- **טקסט שיעור:** `js/data/lessons.js` (השדה `quiz` שם לא בשימוש – השאלות ב-quizzes.js).
- **שאלות:** `js/data/quizzes.js`. לכל שאלה: `t` (סוג), `q`, תשובה (`a` / `accept` / `items`), `ex` (הסבר), `sec` (מספר הפסקה בשיעור, מ-0) ו-`twin` (שאלת תאומה).
- **משימות ומילון:** `js/data/extras.js`.

אפשר לערוך קבצים ישירות באתר GitHub (פותחים קובץ ← סמל העיפרון ← Commit changes), ו-Vercel יעדכן את האתר.
